WHY TELEPORT

A native macOS file transfer client, built for people who live in both the Finder and the terminal.

FTP · FTPS · SFTP

Connect to any server over FTP, FTPS, or SFTP — with SSH key authentication and host-key verification built in.

Scriptable CLI

tport brings every core feature to the terminal — automate transfers and script deployments from any shell.

Resume & Conflict Handling

Interrupted transfers pick up where they left off. Overwrite-if-newer conflict resolution keeps files in sync.

Native SwiftUI

Built for macOS from the ground up — fast, lightweight, and right at home on your Mac.

GET TELEPORT

Install with Homebrew or grab the notarized disk image — either way, tport comes along.

HOMEBREW

brew install --cask jeffcaldwellca/tap/teleport-ftp

Installs Teleport.app and links tport onto your PATH. Update later with brew upgrade --cask teleport-ftp.

The cask is teleport-ftp — the bare teleport name in Homebrew belongs to an unrelated SSH product.

DIRECT DOWNLOAD

Download for Mac

Open the .dmg and drag Teleport to Applications. Signed and notarized, so it opens without Gatekeeper warnings.

Want tport too? Settings › General › Install Command Line Tool.

FREQUENTLY ASKED QUESTIONS

What is Teleport?

Teleport is a free, open-source native macOS app for transferring files over FTP, FTPS, and SFTP.

Is Teleport free?

Yes. Teleport is free and open source, licensed under the GNU General Public License v3.0.

Does Teleport have a command-line interface?

Yes. Teleport includes tport, a scriptable command-line tool for automating file transfers from the terminal or shell scripts.

What macOS version does Teleport require?

Teleport requires macOS 14 (Sonoma) or later.

Where can I download Teleport?

Teleport is available for free from the Releases page on GitHub, or with Homebrew: brew install --cask jeffcaldwellca/tap/teleport-ftp.

Is Teleport a free alternative to Cyberduck, Transmit, ForkLift, or FileZilla?

Yes. Teleport is a free, open-source, native SwiftUI alternative for FTP, FTPS, and SFTP transfers on macOS, with a bundled scriptable CLI (tport). It focuses on FTP/FTPS/SFTP rather than the broader cloud-storage support in apps like Cyberduck, Transmit, and ForkLift.

Is Teleport related to the Teleport infrastructure access platform by Gravitational?

No. This Teleport is an unrelated, independent macOS FTP/FTPS/SFTP desktop client and is not affiliated with Gravitational's Teleport access platform.
